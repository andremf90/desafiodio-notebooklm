# Objetivo:
Criar um segundo cérebro baseado nos ensinamentos de investigação do Detetive Sherlock Holmes, e sua metodologia para solucionar casos.
Desafio de projeto prático focado na criação de um LMManager utilizando a Inteligência Artificial como ferramenta de aprendizagem ativa.

---

## Contexto e Objetivos
O objetivo deste repositório é consolidar os conhecimentos de investigação e solução de casos do Detetive Sherlock Holmes, usando como base as fontes de pesquisa as fontes da internet, que serve como a base indispensável para o domínio criação do cérebro de IA. A escolha do tema se justifica pela necessidade de construir uma base sólida de raciocínio lógico e análise crítica de problemas, preparando uma solução embrionária que possa ser utilizadas por departamentos de investigação, com estruturas pensamentos e metodologias complexas e o uso de IA no trabalho.
